# Brand aesthetic and art-direction playbook

**Start with supplied authority, not an agent's taste.** Brand strategy defines audience and positioning; brand identity defines recognized assets and voice; aesthetic direction defines how the software feels through color, type, photography, illustration, space, motion and graphic detail.

## Direction-setting procedure
1. Find existing brand guidelines, design-system tokens and asset licenses. If absent, state the unknowns and propose **tentative** directions, not fictional rules.
2. Describe 3–5 specific target qualities (e.g., restrained, warm, precise, energetic). Tie each to a product goal and an example of what would violate it.
3. Assemble an **annotated and rights-aware** reference set representing palette, typographic personality, imagery treatment and layout. Avoid copying third-party visual designs verbatim.
4. Choose design rules that can be implemented and validated: semantic palette roles, type scale, photographic lighting/crop, icon family, spacings, motion restraint, component states.
5. Show two small direction variants **only when an actual decision is open**, comparing audience fit, production cost, readability and consistency. Default to existing identity when present.
6. Translate the approved direction to tokens and components; do not promise cohesive art direction if each page has new arbitrary CSS.

## Review rubric
- Can a screen without a visible logo still look related to the product's other screens?
- Are emotional/color associations context- and audience-tested instead of universalized?
- Are there accessible actual color pairings, meaningful states, licensed imagery/fonts, readable content and an appropriate user journey?
- Does design consistency make task completion easier, rather than turning all product views into campaign pages?

## Acceptance
A brief-to-design evidence matrix names each attribute, implementation choice, counterexample and verification. Retain deliberate exceptions for marketing vs operations. Avoid subjective 1–10 aesthetic ratings without a measured rubric.
